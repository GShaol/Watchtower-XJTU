# 0.1.0 — Initial Community edition

- Nine opt-in modules: Scholar, XJTU mail/OA, OpenReview, TIFS/TDSC/ToN/TMC/JSAC.
- Independent local account/session storage; no personal-edition migration.
- macOS native window, menu bar, notifications and Keychain helper.
- Separate polling and notification schedules; latest-three lists.
- No SMTP or Notion functionality.
- Bilingual README, clean build scripts and offline release checks.

Apple Silicon only; locally ad-hoc signed, not notarized. Real authenticated
access remains subject to each website's availability, account restrictions and
layout. JSAC EDAS topics are not supported. Never distribute runtime data.
